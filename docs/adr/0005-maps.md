# ADR 0005: Maps — MapLibre GL + Protomaps PMTiles

- **Status:** Accepted
- **Date:** 2026-05-21

## Context

Two map surfaces: the wishlist/visited places map and the date-ordered path map. Both must work offline once the user has loaded the region.

## Decision

- **Renderer:** MapLibre GL JS (open fork of Mapbox GL, vector tiles, GPU-accelerated).
- **Tiles:** Protomaps PMTiles. A single `.pmtiles` archive contains a region's worth of vector tiles; HTTP range requests fetch only what's viewed.
- **Offline:** Service worker (Workbox) caches PMTiles range responses by URL+Range header. Per-trip pre-download flow downloads a bounding-box slice on Wi-Fi.
- **Layers:**
  - `accommodations`: line + circle (date-sorted polyline + check-in markers).
  - `places-visited`: circle, distinct icon, derived from `place.visited === true`.
  - `places-wishlist`: circle, different icon, `place.visited === false`.

## Alternatives considered

- **Leaflet + OSM raster.** Per-zoom PNG tiles, harder offline caching, dated rendering on mobile. Rejected.
- **Mapbox.** Paid above free tier; service lock-in. Rejected.

## Consequences

- One JS library to learn; reasonably small bundle if we tree-shake.
- PMTiles slices can be 100MB+; surface download size to the user before fetching.

## Sharp edges

- Service worker caching strategies for Range requests are tricky. Workbox `RangeRequestsPlugin` handles it; verify it works with our PMTiles CDN.
- Vector tile styles need a font stack and sprite. Use Protomaps' default style as a baseline.
